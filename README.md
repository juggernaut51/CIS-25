So it looked like the example we were given was fully complete so I decided to just spruce it up a little

I left the varaible names the same since they all seemed accurate and fitting. I added fees becuase all banks have fees. I added tolerance isFrozen for my account freeze protocal. I needed a setter for setting tolerence so I added a setter function for that. I added a getter so I could check if the account freeze was active or not. I modified deposit so that way it wouldnt work when the account was frozen. I added an overdraft function to cause fees when the account was overdrafted. The overdraft gets saved to the text file as well. This is also where an account freeze can trigger. I added a pay fee functon though i never called it, but it felt right to have. The make purhcase function checks for frozen status and then it will attempt purchase. Declined purchases are now recorded. Display balance doesnt work when frozen becuase the only thing you can do with a frozen account is pay fees. This brings us to the freeze account function which gives a message and then records the current balance and fees as a constant so they dont get changed later. The save transaction function just records transactions to the text file. I added locations for fun since I added scam charges.

in main we make a bank account object called myAccount. I have the default tolerence at $500, so they can rack up fees. I do allow users to input a custom tolernce if they choose. After a couple real purches the fradulatent purches go until the account is locked out.
